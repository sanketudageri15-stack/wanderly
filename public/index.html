FAQ

Questions, answered

How accurate are the estimates?

Estimates use typical daily costs per destination and travel style plus an average flight price. They're a planning baseline — your actual costs will vary with season, booking time and choices.

Which currencies are supported?

You can view prices in INR, USD, EUR, GBP, JPY, AED, THB, IDR, CHF, AUD and SGD. Exchange rates in this version are fixed reference values, so treat conversions as indicative.

Where is my data stored?

Trips, expenses, itineraries and packing lists are saved by the Wanderly server in a local JSON file. Run it yourself and the data stays with you.

Can I track a trip with several travelers?

Yes. Set the traveler count when you create a trip and the dashboard shows the per-person daily budget alongside the totals.

Can I add destinations that aren't listed?

The destination list lives in the server's data file, so adding more is a matter of adding an entry with its daily costs and a photo.
